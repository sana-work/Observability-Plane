Here's every file in ai_obs_sdk/, in dependency order (each file only imports from files above it), with what it does and why it's written that way.

pyproject.toml — packaging
Declares the package (ai-observability-sdk, Python ≥3.11, hatchling build) and its dependencies: pydantic/pydantic-settings (models + env config), confluent-kafka (the producer), structlog (JSON logging), the OpenTelemetry stack (API, SDK, OTLP-gRPC exporter, FastAPI/httpx/asyncpg auto-instrumentation), prometheus-fastapi-instrumentator (the /metrics endpoint), and httpx (prompt-registry client). The [dev] extra adds pytest/fastapi/ruff. Also holds pytest and ruff config so tooling behaves identically for everyone.

.env.example — the configuration reference
Not code — documentation that runs. Every AI_OBS_* variable with a comment: the three required identity vars, the master switch, the full Kafka block (including the commented-out SASL section for prod), OTLP endpoint, logging, metrics, prompt registry. A service team copies this into Helm values and edits — they never read config.py.

contracts/ — the frozen wire contract (4 files)
event_schema.py — the ObsEvent Pydantic model: the envelope every event must match. Field groups: identity (event_id auto-uuid, schema_version="1.0", event_type, telemetry_type), time (timestamp/emitted_at, auto UTC ISO), correlation (correlation_id, request_id, trace_id, span_id, parent_span_id), ownership (service_name, component, environment, application_id, lob, tenant_id, user_id — with the comment recording the raw-SOE-ID decision), outcome (status, latency_ms, error_code, http_status), and payload: dict for everything domain-specific. Three @field_validators reject unknown event_type, service_name, telemetry_type — constructing an invalid event raises immediately.

event_types.py — the 50-value EventType string enum in 10 groups (request 4, orchestration 6, kafka 4, agent 8, llm 5, tool 4, rag 5, guardrail 4, feedback 3, document 7), ending with assert len(EventType) == 50 so nobody adds a 51st casually. service_names.py — same pattern for the 8 services. __init__.py — re-exports plus the "vendored — do not edit here" warning; these files are byte-copies of observability-iac/contracts/ and CI diffs them on every PR.

Why vendored instead of imported: services must be self-contained after pip install — they never have the IaC repo at runtime. The drift check replaces the import.

config.py — all configuration
One class, ObsSettings(BaseSettings), with env_prefix="AI_OBS_". Every field is automatically an env var. Three have no default (service_name, lob, application_id) so an unidentified service fails at startup instead of emitting anonymous events. Notable fields: enabled (the kill switch — false turns every SDK call into a no-op), the Kafka tuning block (linger_ms=50, lz4, 100k queue cap, 10s delivery timeout, optional SASL), trace_sample_ratio, log_json, prompt_cache_ttl_seconds (the Redis stand-in knob). get_settings() is @lru_cached — the environment is read once per process; every other module calls this instead of receiving config as arguments. Rule: no other file in the package reads os.environ.

context.py — request-scoped identity
The ObsContext dataclass: correlation_id (defaults to a fresh uuid4), request_id, trace_id, span_id (16 hex chars — the W3C width, from secrets.token_hex(8)), parent_span_id, usecase_id, agent_id, tenant_id, user_id. Stored in a contextvar — Python's async-safe thread-local: whatever the middleware binds is visible to every function called during that request without argument-passing, and concurrent asyncio requests can't see each other's context.

Three functions + one method carry all the semantics: bind_context(ctx) returns a token, reset_context(token) restores (the middleware always resets — leaked context across asyncio requests is a nasty bug), get_context() returns the current context or creates a fresh detached one (so background jobs and schedulers never crash — they just start their own trace), and ctx.child() returns a copy with parent_span_id = old span_id and a fresh span_id — the single mechanism behind span-tree nesting.

hashing.py — content hashes
Two functions: prompt_hash(text) and query_hash(text) — sha256, first 16 hex chars. These exist so thousands of events can say "the same prompt" without carrying the full text. The docstring states explicitly what this module is not: a privacy control — user identity is carried raw by platform decision, and there is deliberately no user-hashing function here.

kafka_headers.py — W3C trace propagation
Wraps OTEL's TraceContextTextMapPropagator. inject_trace_headers(correlation_id) reads the currently-active OTEL span, serializes it into the standard traceparent header (plus tracestate if present), appends a correlation_id header, and returns Kafka-shaped [(str, bytes)] — attached to every produced message so consumers continue the same distributed trace instead of starting a new one. extract_trace_context(headers) is the consumer-side inverse (used by the Enrichment Consumer and by our own services that consume Kafka). current_trace_ids() returns the active span's trace/span IDs as hex strings — the emitter stamps these onto events so an event can be joined to its Tempo trace.

emitter.py — the heart
Two things live here. KafkaEmitter wraps confluent_kafka.Producer with config from settings: enable.idempotence=True (retries can't duplicate), lz4, linger.ms=50, bounded local queue, optional SASL, client.id=ai-obs-sdk.<service>. Its _on_delivery callback (runs on the producer's poll thread) counts delivered/dropped and warn-logs failures. emit() calls produce(topic, key=correlation_id, value=event.model_dump_json(), headers=...) then poll(0) — and here is the core mechanic: produce() never does network I/O; it appends to librdkafka's in-memory queue in microseconds while a background C thread batches, compresses, sends, and handles acks. BufferError (queue full — e.g., long broker outage) is caught and the event is dropped with a warning — the deliberate alternative to blocking. flush() is atexit-registered so clean shutdowns drain the queue. It's a module-level singleton behind double-checked locking.

emit_event(event_type, *, status, latency_ms, error_code, http_status, payload, component) is the one public funnel: no-op if disabled; assembles the ObsEvent from three sources — settings (service identity), the contextvar (request identity incl. user_id), and current_trace_ids() (live trace identity); construction validates against the contract (a typo'd event type dies in unit tests, never in production); hands to the emitter. The entire body sits in try/except Exception: log; return — the never-raises guarantee that lets this code live on eight production request paths.

tracing.py — OTEL → Tempo
init_tracing(app): builds a TracerProvider with resource attributes (service.name, service.namespace=ai-services-platform, environment, lob — these become searchable dimensions in Tempo), a ParentBasedTraceIdRatio sampler (respects the caller's sampling decision, applies the ratio only at trace roots), and a BatchSpanProcessor exporting OTLP gRPC to Tempo's :4317. Given the FastAPI app, it instruments every route (excluding /metrics, /health, /ready); httpx and asyncpg auto-instrumentation are wrapped in try/except because not every service uses both. An _initialized guard makes repeat calls no-ops. get_tracer() hands the decorators their tracer. This is the infrastructure trace layer — the AI-quality trace view is rebuilt from Kafka events; both share correlation_id.

log_config.py — structlog JSON with automatic correlation
configure_logging() builds one processor chain: merge contextvars → _add_obs_context (the custom processor that reads the current ObsContext and stamps correlation_id/span_id/request_id onto every log line — the whole reason logs join to events and traces) → level, logger name, ISO UTC timestamps, exception formatting → JSON renderer (or pretty console when AI_OBS_LOG_JSON=false for laptops). Crucially it also routes stdlib logging through the same formatter via ProcessorFormatter, so uvicorn's and confluent-kafka's own log lines come out in the identical JSON shape — Fluent Bit parses exactly one format.

middleware.py — where a request's identity is born
ObservabilityMiddleware.dispatch() per request: skip the four operational paths; build the ObsContext from inbound headers — X-Correlation-ID or mint a uuid (this line is where the platform-wide ID originates), X-Request-ID, X-Usecase-ID, X-Tenant-ID, and X-User-ID/X-SOE-ID copied verbatim into user_id; bind the contextvar; emit REQUEST_RECEIVED; run the handler. An exception emits REQUEST_FAILED (error_code = exception class name) and re-raises — the SDK observes failures, never swallows them. A response emits REQUEST_COMPLETED (or FAILED when status ≥500) with latency and http_status, then echoes X-Correlation-ID on the response so a user's bug report can quote the exact trace. The context token is always reset.

init_observability(app) is the one-liner services adopt: configure_logging() + init_tracing(app) + add_middleware(...) + the Prometheus instrumentator exposing /metrics with per-route latency histograms. This file is also the main real-world adaptation point (COIN-JWT claim extraction — see IMPLEMENTATION.md §8).

decorators.py — the instrumentation API
One factory, _make_decorator(started, completed, failed, span_name, static_payload_builder, timeout_event, finalize), produces all four decorators, so their behavior can't drift apart. Each wrapper (sync and async, chosen via inspect.iscoroutinefunction): binds get_context().child() (nesting) → emits *_STARTED with the decorator's static kwargs → runs the function inside an OTEL span → on success emits *_COMPLETED with wall-clock latency_ms and the merged payload; on exception emits *_FAILED — or the timeout event when it's a TimeoutError (TOOL_CALL_TIMEOUT, AGENT_TIMEOUT) — with error_code and a 500-char-truncated message, then re-raises; always resets the context token.

Payload merging has three sources, later wins: static decorator kwargs ∪ result.obs_payload (a dict the wrapped function attaches to its return value — how runtime facts like token counts get in without changing function signatures) ∪ an obs_extra= kwarg from the caller. The LLM finalizer (_llm_finalize) additionally computes total_tokens + estimated_cost_usd when token counts are present, and replaces any prompt_text key with its prompt_hash — full prompts never ride in events.

cost.py — the producer-side price table
A PRICING dict of per-1k-token (input, output) USD per model, a DEFAULT for unknown models, and estimate_cost_usd(model, in_tokens, out_tokens). Explicitly an estimate: it makes cost visible on events even before enrichment, and the Enrichment Consumer overwrites it from the authoritative model_pricing table. The rows must stay identical to the IaC pricing seed — an IaC policy test fails the build if they diverge.

prompts.py — versioned prompt fetching
get_prompt(template_id, version="active"): httpx GET against the control-plane API (3s timeout), deserialized into a frozen Prompt dataclass (template_id, version, text, prompt_hash, ab_bucket, plus a .format(**vars) helper), behind a thread-safe in-process TTL cache (_TTLCache, 300s default). The cache is the explicit Redis stand-in — swapping to a shared cache later touches only this module. No registry URL configured raises a clear RuntimeError telling teams to keep a baked-in fallback (relevant until Phase Q ships the API).

__init__.py — the public surface
Re-exports everything a service should touch — init_observability, emit_event, the four decorators, get_prompt, the contract types, context helpers — with a docstring showing the two-line quick start. Anything not exported here is considered internal. (py.typed alongside it tells type checkers the package ships annotations.)

tests/ — 17 tests, all broker-free
conftest.py sets deterministic AI_OBS_* env and defines the FakeEmitter fixture — captures ObsEvents in a list, monkeypatched over the singleton, which is why the entire suite needs no Kafka. test_contract.py is the merge gate: counts frozen at 50/8, round-trip, unknown-type/service rejection, every type emittable. test_emitter.py: envelope fully populated from settings+context (including user_id), bogus event type swallowed silently, detached context auto-correlates. test_decorators.py: STARTED/COMPLETED pair with computed cost and correct span parentage, async failure → FAILED + re-raise, TimeoutError → TOOL_CALL_TIMEOUT, obs_extra merging. test_middleware.py: event pair sharing one correlation_id, ID minted+echoed when absent, exception → REQUEST_FAILED, user_id captured verbatim (SOE12345), /health emits nothing.

ci/sdk-ci.yml runs ruff → contract tests → full suite → the vendored-contract drift diff.
